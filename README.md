# KBHS
Coursework submission for a Knowledge-Based and Hybrid Systems module contributing to MSc AI @ UWE. An essay with minimal code.
### Task
Choose a problem from a previously completed Knowledge-Based workbook in order to design and describe an alternate Hybrid solution.
## Contents
An essay about RAG-based knowledge graph retrieval, with a very basic `langchain`/`langgraph` implementation to demonstrate proof of concept.
